# Employee Attrition Prediction

## About the Project

The main aim of this project is to understand why employees leave a company and to predict employee attrition using machine learning.

## Objective

The main objectives of this project are:

* To understand the employee dataset.
* To find the reasons related to employee attrition.
* To clean the data.
* To understand the data using charts and analysis.
* To train machine learning models.
* To predict whether an employee may leave the company.

## Dataset

The dataset contains **1470 rows and 35 columns**.

It contains information about employees such as:

* Age
* Department
* Job Role
* Job Satisfaction
* Job Involvement
* Education
* Monthly Income
* Performance Rating
* Work-Life Balance
* Business Travel
* Attrition
